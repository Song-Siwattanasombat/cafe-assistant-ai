# 🍅 School Café Assistant AI

School Café Assistant AI is an educational portfolio prototype by **Song Siwattanasombat**. It explores how a local AI assistant can help users browse sample school café menus, prices, ingredients, and allergen information.

The prototype contains menu data for **7–11 September 2026** only.

## Features

- Daily hot and cold menus
- Ingredient, allergen, and dietary filtering
- Food-name and price-based searches
- Streaming responses from a local Ollama model

## Built With

- Next.js and TypeScript
- Ollama and Llama 3.2

## Run Locally

```bash
npm install
ollama create dai-bot -f Modelfile
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Disclaimer

This project is still in development. AI responses may be slow, incomplete, or inconsistent. It was created for educational and portfolio purposes and is not affiliated with any institution.
